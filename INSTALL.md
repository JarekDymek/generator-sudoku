# Generator Sudoku — instalacja

Aplikacja: https://jarekdymek.github.io/generator-sudoku/

- Android: otwórz adres w Chrome → menu → Zainstaluj aplikację / Dodaj do ekranu głównego.
- iPhone/iPad: otwórz w Safari → Udostępnij → Dodaj do ekranu początkowego.
- Laptop: otwórz adres w Chrome lub Edge → Zainstaluj aplikację.

Po pierwszym pełnym wczytaniu działa offline. Wydruk: 4 sudoku na A4 pionowo, opcjonalna strona z rozwiązaniami.

Poziomy (wpisane cyfry): łatwy 40–41, średni 30–35, wysoki 25–30, PRO 17–20.
